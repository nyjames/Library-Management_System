# General user stories overview

As a user, I want to be able to look up books within the library's database using this application.

As a user, I want to be able to add, update, and remove books from the library's database using this application.

As a user, I want to be able to search with the author's name or book's title.

As a user, I want the application to perform its actions with minimal delay.

As a user, I want the application to provide clear and concise messages if an error is encountered.

As a user, I want the application to handle errors gracefully if encountered.

As a user, I want the searching feature to be intuitive and easy to use.

As a user, I want the application to provide detailed information about the book that was searched.

As a user or developer, I want the application to have useful documentation that explains all parts of the application and how to use it.

As a developer, I want the application to be scalable so new features can be added without compromising other features.
