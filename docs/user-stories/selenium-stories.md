# User stores related to Selenium

### As a tester, I want to automate all form submissions to verify the application processes data correctly.
- Acceptance Criteria:
  - Automation of all submittable forms
  - Each form submits without error

### As a tester, I want to automate the login process to ensure the system correctly authenticates valid credentials and rejects invalid attempts.
- Acceptance Criteria:
  - Simulation of fake user account successfully logging into an account
  - Simulation of invalid login attempt and verify error message

### As a tester, I want to automate the search feature, so I can verify the results correctly matches what was entered.
- Acceptance Criteria:
  - Automation of a random search
  - Verify search results matches what was searched
